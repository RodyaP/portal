# Переговорные · УГМК-Застройщик

Приложение бронирования двух переговорных: FastAPI, PostgreSQL, локальный первый администратор, вход сотрудников через AD/LDAPS и роли внутри портала. Развёртывание — Docker Compose с HTTPS-прокси Nginx.

Почтовые уведомления: адреса организатора и участников читаются из поля `mail` в AD. В «Управление → Почтовые уведомления» настройте корпоративный SMTP и включите отправку. События создания, изменения, отмены, продления и досрочного завершения отправляются каждому адресату отдельно; исключённый участник получает уведомление об исключении. Письма содержат время, переговорную, сведения о встрече, ссылку и `.ics` для ручного импорта. Подробности настройки и очереди — в [DEPLOY_DOCKER.md](DEPLOY_DOCKER.md#почтовые-уведомления).

## Запуск на сервере

Подробная инструкция: [DEPLOY_DOCKER.md](DEPLOY_DOCKER.md). Нужны Docker Engine и Compose 2.24.4+, DNS-имя, сертификат HTTPS и доступ к контроллеру AD по TCP 636.

Из каталога с `compose.yaml`:

```sh
python3 deploy/configure.py
# Укажите PUBLIC_ORIGIN в .env, установите сертификаты по инструкции.
docker compose up -d --build
docker compose ps
```

Первый вход создаёт локального администратора с вашим паролем и требует `BOOTSTRAP_TOKEN` из `.env`. После настройки зайдите в «Управление», подключите AD, найдите сотрудника и назначьте администратора. Локальная учётка остаётся для аварийного доступа.

## Локальная проверка с базой

```sh
python deploy/configure.py
docker compose -f compose.yaml -f compose.local.yaml up -d --build
```

Открыть **http://localhost:8080**. Этот режим публикует порт только на loopback и разрешает HTTP исключительно для localhost. Используйте то же имя `localhost`, не IP: проверка Origin строгая. Локальный просмотр не требует настроенного AD; подключение сотрудников потребует доступной корпоративной сети/VPN.

## Роли и вход

- Обычный сотрудник AD — бронирование от своего имени и доступ к собственным встречам и встречам, где он участник.
- Бронирование по поручению — отдельное право выбора другого организатора.
- Администратор портала — работа с чужими бронями с указанием причины, блокировка переговорных, аудит, настройки AD, назначение ролей.
- Локальный администратор — те же административные возможности без зависимости от AD.

Пароли сотрудников проверяются LDAP bind через LDAPS и не сохраняются. Для поиска применяется служебная учётка с правами чтения. Её пароль хранится в PostgreSQL в зашифрованном виде; ключ находится в `.env`. Сессии действуют 8 часов, cookie HttpOnly, SameSite=Strict, в рабочем режиме Secure. Права и состояние учётки AD перечитываются при каждом запросе. Роли назначаются по objectGUID: переименование сотрудника не меняет назначения.

Автоматического входа Windows/Kerberos в этой версии нет: используется форма доменного логина и пароля. Права из групп `bron`/`secretary` автоматически не импортируются — их назначает администратор портала. Если AD недоступен, вход и запросы сотрудников завершаются ошибкой; локальный администратор продолжает работать.

## Проверки

```sh
docker compose -f compose.test.yaml up --build --abort-on-container-exit --exit-code-from tests
docker compose -f compose.test.yaml down
```

Тестовый Compose использует отдельную временную базу без рабочего volume. Не задавайте рабочую БД в `TEST_DATABASE_URL`: интеграционные тесты очищают таблицы.

Для Python без Docker:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Без `TEST_DATABASE_URL` интеграционные тесты будут пропущены. Текущий результат проверки описан в [STATUS.md](STATUS.md).

Статический сервер `python -m http.server --directory dist` запускает только демонстрацию с вымышленными данными в localStorage. Для общего хранения, входа и ролей используйте backend/Compose. Статические демонстрационные брони не переносятся в PostgreSQL автоматически.

Документ [docs/ARCHITECTURE_V1.md](docs/ARCHITECTURE_V1.md) сохраняет исходные требования и прежнюю схему Apache/Kerberos. Для текущей версии инструкции входа и развёртывания берите из этого README и DEPLOY_DOCKER.md; прежние systemd/Apache-шаблоны не используются Compose.
